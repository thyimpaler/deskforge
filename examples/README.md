# examples

Offline sample data. The tests and the configurator preview read these files, so nothing makes a network call.

| File | Shape of |
|---|---|
| weather.json | an Open-Meteo `current` response |
| prices.json | a CoinGecko `simple/price` response (two coins, with 24 h change) |
| status.json | the Claude status page `status.json` |
| nowplaying.txt | what the now-playing helper writes: song, then artist |

All values are made up.
