# addons

Optional extras, all off by default. Turn one on in `config\desk.json` under `addons`, then install again.

| Addon | What it adds | Network |
|---|---|---|
| [tape](tape/) | BTCUSDT 15 m candles on the wallpaper | Binance public API |
| [depth](depth/) | BTCUSDT order-book ladder | Binance public API |
| [wave](wave/) | audio spectrum on the dock edge | none |
| [mood](mood/) | wallpaper tint from the 4 h BTC move | Binance public API |
| [alert](alert/) | a band for new unread messages | none |

Tape, Depth and Wave cost more CPU than the core skins. None needs a key. Tape and Depth draw fixed-size boxes
and the Mood label sits at a fixed spot; how they sit on screens other than 1920 x 1080 is not verified yet.
